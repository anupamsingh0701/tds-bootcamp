Chest X-Ray Thoracic Disease Classification

Automating thoracic disease detection from medical X-rays using ResNet50.

Deep Learning

Project Overview

Developed an automated classification model to detect thoracic diseases from chest X-ray images. This is a 20-class classification task complicated by imbalanced medical data and asymmetric misclassification costs (where missing a disease carries a severe penalty of -5).

The implementation fine-tunes a pre-trained ResNet50 backbone using a phased strategy, dynamic data augmentation, and Label Smoothing regularizer inside the loss function.

Architecture & Strategy

A key finding was the effectiveness of a Phased Fine-Tuning approach. In the first 3 epochs, the ResNet backbone was frozen, training only the newly added linear classification head with a learning rate of 1e-3. In subsequent epochs, the entire network was unfrozen and trained at a lower learning rate of 1e-4.

Config Management

Conflict Mechanics

In git configurations or distributed files, a three-way merge compares two modified branches (Branch A, Branch B) with their common ancestor (Base). A conflict arises when a key is modified by both Branch A and Branch B, but their updated values are different.
